# FourWay Dash

A small reflex game I made with Godot. An arrow shows up and you answer it in the same direction before it disappears, and you keep going until the level's timer runs out. Later levels add colours that mirror or rotate the arrows. There are 16 levels.

I originally published it on Google Play, but I've since changed my mind about keeping it there, so this is where it lives now, playable in the browser:

**[Play FourWay Dash](https://amojovic.github.io/fourway-dash/)**

Arrow keys on a computer, swipes on a phone. Your progress is saved in your browser.
